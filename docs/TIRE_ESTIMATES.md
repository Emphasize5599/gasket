# Tire graphics: estimates, not measurements

1. Same-set mileage entry requires a finite nonnegative mileage, an explicit rotation answer (including Not sure), and a tire type before Done/Back can commit it. Zero miles is valid; blanks are not zero. Measured mode requires a depth instead. Edits remain in a separate draft until committed; discard confirms and leaves the saved tires unchanged.
2. Wheel colors use the same wear scale as individual tires. Regularly rotated matched tires are estimated evenly. For skipped/irregular rotations, broad axle multipliers illustrate drivetrain-related uneven wear: FWD front-heavy, RWD rear-heavy, AWD/4WD modest front bias. Unknown drive uses the existing set-wide rotation penalty. No unsupported left-versus-right differences are invented; a dually's inner/outer pair shares its axle estimate.
3. Manufacturer mileage warranty takes precedence, followed by the existing UTQG-based approximation. With neither, type defaults are planning assumptions: touring/highway 60k, general/all-terrain 50k, mud 40k, winter 35k, summer/UHP 30k, max/extreme performance 25k, track/competition/drag 10k miles. They are not empirical predictions for a specific tire; individual tires can differ substantially. New-depth assumptions and half-32nd rounding remain approximate.
4. Source guidance supports uneven wear and regular rotation, not these numerical coefficients. [Tire Rack](https://www.tirerack.com/upgrade-garage/where-to-install-new-pairs-of-tires) explains faster front wear on FWD cars and deeper tires on the rear. [Michelin's rotation guide](https://www.michelinman.com/auto/auto-tips-and-advice/tire-maintenance/tire-rotation) directs owners to the appropriate pattern/interval and warranty conditions. [Michelin's replacement guidance](https://www.michelinman.com/auto/auto-tips-and-advice/tire-buying-guide/when-do-i-need-new-tires) stresses inspection rather than mileage alone.
5. The existing centralized generalized-estimate warning remains. Rotation help explains that axle colors are broad assumptions and asks for actual tread/pressure checks. Measured values take precedence; colors must never certify roadworthiness, traction or tire condition.
