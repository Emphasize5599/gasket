# Open work

The single backlog for Gasket: features, defects, validation and release decisions. Updated through **0.0.234**, 2026-10-22, including the owner's completed-item confirmations. Add new work here. Remove completed work; move retired, irrelevant or out-of-scope ideas to [RETIRED_WORK.md](RETIRED_WORK.md). Historical implementation notes stay in `CHANGELOG.md`, `CLAUDE.md` and `KEYLESS_EXPERIMENT.md`; `COMPLIANCE.md` is a service/rights reference, not a second task list.

Keep existing item numbers so references remain valid; gaps are intentional. New entries start at 61 (do not reuse completed/retired numbers). Items are grouped by category, so numeric order does not imply priority.

Latest research additions: **2026-10-27**, after 0.0.282; older entries were not re-audited in this pass.

### Vehicles and fuels

3. Still unread, so off by default in Parameters' network list: Electrify America and EVgo (prices only in their apps or at the charger; owner idea: watch what the apps request, without defeating app protections, on a machine that can run an Android emulator, not a cloud session), EV Connect, Shell Recharge, Rivian Adventure, Walmart and other / non-networked stations. Also still open: an efficient maintained OCM bulk snapshot (the current OCM option is a route API) and phone validation of the full offline inventory download and long-route coverage.
50. [ ] **Validate and broaden EV/hydrogen energy, speed and fill models.** Initial v3 integration shipped in 0.0.237: hourly-weather reuse, explicit one-car TUM LFP profile, generic EV thermal/taper estimates, metered-energy accounting, speed scenarios and corrected Python reference. See [docs/PROPULSION_MODELS.md](docs/PROPULSION_MODELS.md). Remaining: independent raw-fit verification; model/chemistry-specific road-load curves, better charge curves than Open EV Data's (0.0.264 bundles them and lets the user type one) and their temperature response; verified power sharing; hydrogen pressure, temperature, pre-cooling and back-to-back fill data; validation of hydrogen speed/weather behavior; time/session tariff handling; and a validated joint speed/stop/charging optimizer. Existing five-speed comparisons are estimates, not a proven global optimum. Coordinate with station quality (51) and vehicle comparison (49).

60. [ ] **Validate DC charging curves and departure charge targets for U.S. battery EVs.** Start with Tesla Model 3/Y, then Chevrolet, Ford, Hyundai, Kia, Rivian, Cadillac, GMC, BMW, Nissan, Volkswagen and Toyota. Next cover Acura, Audi, Dodge, Fiat, Genesis, Honda, Jaguar, Jeep, Lexus, Lucid, Mazda, Mercedes-Benz, MINI, Mitsubishi, Polestar, Porsche, Subaru, VinFast and Volvo, plus lower-volume U.S. makes such as Fisker, smart and Wheego where applicable. Use the [EPA U.S. vehicle roster](https://www.fueleconomy.gov/feg/download.shtml) to find remaining makes and retired models, and [Cox new/used market data](https://www.coxautoinc.com/insights/ev-market-monitor-september-2026/) to prioritize. Record variants without DC charging separately. Coordinate with item 50 and reuse [existing propulsion evidence](docs/PROPULSION_MODELS.md) and the academic reference under [research/charge-fill-v3](research/charge-fill-v3/README.md).

    For Tesla, map Model 3/Y first, then S/X and Cybertruck, by U.S. model year, trim, drive, build range, pack family/chemistry, usable capacity and software where supported. Rank measured matches by pack and test conditions. Label the closest verified proxy or generic estimate when the exact pack is unknown. Use repeatable measured sessions and check predicted elapsed time across the charge ranges the planner uses. Start with the [U.S. 2021 Model 3 Long Range V3 session](https://insideevs.com/news/506520/tesla-model-3-supercharger-test/), the [P3 test curves](https://www.p3-group.com/wp-content/uploads/2024/04/P3-Charging-Index-en-220718-1.pdf), and the [TUM LFP data](https://doi.org/10.14459/2024mp1735494) for the separate LFP profile. Retain source and test conditions for each curve.

    In Garage, add an installed high-voltage battery profile selector with Auto (factory estimate), compatible pack profiles, and Other / unknown. Use explicit VIN-decoded battery fields or documented make/year/plant rules as factory hints. Keep a manual installed-pack selection through VIN refreshes, including service replacements. If the pack changes, request curve confirmation again and recalculate charging time, usable capacity and departure targets using the selected profile. See the [NHTSA battery fields](https://vpic.nhtsa.dot.gov/api/vehicles/GetVehicleVariableList?format=json) and [Tesla VIN decoding rules](https://service.tesla.com/docs/Model3/ServiceManual/en-us/GUID-0C797294-574D-4EE4-8017-C339A7D58411.html).

    Before the first DC-dependent trip for a battery profile, ask the driver to confirm the match, enter observations manually, or explicitly continue with an estimate. Start with manual state-of-charge, elapsed time and optional kW observations, plus charger and preconditioning context. Defer imports until they can be tested. At each charge stop show a rounded-up departure charge percentage for the next planned stop and arrival reserve, alongside estimated minutes. Update the target when the route or energy assumptions change.

51. [ ] **Distinguish EV charging-station quality and limitations.** Give users useful, evidence-backed ways to compare stations beyond advertised peak kW and price: verified equipment/generation, power-sharing arrangements (including the owner's example of older paired Tesla stalls), usable power for the selected vehicle, compatible ports/stall counts, access restrictions/hours, and reliability or outage information where trustworthy sources provide it. Feed verified sharing/power constraints into charging-time estimates (50), route choices and vehicle comparison (49) when implemented; coordinate with price-source work (6).
